# 🧮 Python Calculator

A professional desktop calculator application built using **Python and Tkinter**.

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- % Percentage calculation
- 🔄 Plus/Minus toggle
- ⌫ Backspace
- 🧹 Clear button
- 🕘 Calculation history
- ⌨️ Keyboard support
- ⚠️ Error handling
- 🌙 Professional dark-themed interface
- 🔐 Safe expression evaluation

## 🛠️ Technologies Used

- **Python**
- **Tkinter**
- **AST (Abstract Syntax Tree)**
